  • 本工具分两步：录入机构名称并点击「查询」即反馈最近网点；点击「编制并查看参阅材料」后显示五阶段进度，调取技能全网检索核验资料库、生成证据索引并组装十章 + 两附录的详细材料，完成后弹出全文。

  • 定位共三级：① 已收录机构用全网检索核验的真实坐标；② 未收录机构由同源后端代理取得高德地图 POI 真实坐标（密钥仅服务端持有）；③ 后端不可用、未配置密钥或地图未匹配时，按行政区划中心近似并逐次如实标注。静态托管环境（如 GitHub Pages）无同源后端，自动进入第③级。如需补齐机构事实，请在 WorkBuddy 会话中发起「全网检索补齐」；如需补齐单位画像，发起「画像补齐 <机构全称>」。
